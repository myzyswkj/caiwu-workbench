Supabase 香港反代部署指南

财务工作台云同步恢复方案 · 香港轻量 + Caddy · 约 30 分钟搞定

为什么要这么做？ 你的登录卡死是因为「国内网络 → Cloudflare → Supabase 海外源站」这条跨国链路不稳（浏览器一直 Pending / 522）。 在香港轻量服务器上搭一层反代后，你的浏览器只连香港服务器（国内访问香港很稳），再由香港服务器转发到 Supabase——香港到海外链路优化，两头都通。 Supabase 的数据、账号完全不动，只改前端一个地址。

1买一台香港轻量服务器

  1. 登录 腾讯云轻量应用服务器控制台 → 新建
  2. 地域选 中国香港（关键，别选内地）
  3. 镜像选 Ubuntu 22.04 / 24.04
  4. 套餐选最便宜的即可（约 24 元/月，1 核 1G 足够，反代流量极小）
  5. 付款后进入实例详情，记下公网 IP
买完后在实例详情页点「登录」可直接用浏览器网页登录终端，不用装 SSH 工具。登录后默认是 root。

2准备一个域名并解析到服务器

反代需要 HTTPS，所以需要一个域名（任意域名都行）。

  • 有现成域名：直接用，加一条子域名 A 记录即可（如 supabase.你的域名）。
  • 没有域名：在腾讯云买个 .top / .xyz，几元/年，最便宜够用。

添加解析记录

在域名解析（DNSPod）里加一条：

记录类型主机记录记录值
Asupabase（或任意前缀）你的服务器公网 IP

例如域名是 example.top，主机记录填 supabase，那么反代地址就是 https://supabase.example.top。

解析一般几分钟生效。可在服务器上 ping supabase.example.top 验证是否解析到本机 IP。

3放行防火墙 80 / 443 端口

腾讯云轻量的防火墙在控制台层（不是服务器内的 ufw），必须在这里放行：

  1. 实例详情 → 防火墙 标签 → 添加规则
  2. 加两条：端口 80 协议 TCP 来源 0.0.0.0/0；端口 443 同上
别忘了这步！ Caddy 申请 HTTPS 证书要用 80 端口，访问要用 443。不放行会卡在证书申请失败。

4在服务器上跑一键脚本

在服务器终端（root）粘贴下面两行，把 你的域名 换成上一步的域名：

# 下载脚本（或直接把 deploy/setup-proxy.sh 内容粘贴进去）
curl -fsSL https://raw.githubusercontent.com/myzyswkj/caiwu-workbench/main/deploy/setup-proxy.sh -o setup-proxy.sh

# 执行（替换成你的域名）
bash setup-proxy.sh supabase.example.top

或者，如果 GitHub 不好拉，直接把下面这段整体粘贴到终端（把域名换成你的）：

cat > /etc/caddy/Caddyfile <<'EOF'
supabase.example.top {
    encode gzip
    reverse_proxy https://uuvgvocusrpfakjejbnt.supabase.co {
        header_up Host uuvgvocusrpfakjevbnt.supabase.co
        transport http {
            tls
            tls_server_name uuvgvocusrpfakjevbnt.supabase.co
        }
    }
}
EOF

# 装 caddy 并重启（如已装可跳过安装）
apt-get update -y && apt-get install -y caddy
systemctl enable caddy && systemctl restart caddy
关键点：反代 HTTPS 源站必须 header_up Host 改成源站域名 + tls_server_name 设 SNI，否则 Supabase 的 Cloudflare 不认，会返回 404/522。脚本已处理好。

5验证反代是否通了

在你的电脑浏览器访问（注意是反代域名，不是 supabase.co）：

https://supabase.example.top/

应看到 Supabase 返回的 JSON，类似：

{"message":"No API key found in request"}   # 或 404，都算通

只要不是 522 / 超时 / 一直转圈，就说明反代通了。也可以直接在终端测：

curl -I https://supabase.example.top/
# 期望: HTTP/2 200 或 404，且秒回（<1s）

反代通了之后，把你的反代域名（如 supabase.example.top）发给我。

我会把 js/config.js 里的 SUPABASE_URL 从

常见问题

Q1：浏览器访问反代域名还是 522 / 超时？

检查：①域名是否解析到服务器 IP；②腾讯云防火墙是否放行 80/443；③Caddy 是否在跑（systemctl status caddy）。看日志：journalctl -u caddy -f。

Q2：证书申请失败（浏览器提示不安全）？

Caddy 申请 Let's Encrypt 证书需要 80 端口能被外网访问。确认防火墙 80 已放行、域名已解析。首次启动等 1~2 分钟。

Q3：香港服务器自己连 Supabase 也不稳怎么办？

极少见。香港到 Supabase（Cloudflare）链路优化，通常很稳。若偶尔抖动，Caddy 会自动重试；可加 lb_try_duration 30s 增加重试窗口。

Q4：不想长期花钱？

轻量最便宜约 24 元/月。若觉得贵，可换腾讯云函数 SCF（香港，免费额度），不用买机器，但配置略复杂——告诉我我再给 SCF 方案。
