4获取访问 URL

部署成功后：

  1. 进入函数详情 → 触发管理（或「触发器」）标签
  2. 会看到一个自动创建的 API 网关触发器，带访问路径
  3. 复制那个 不带额外路径前缀 的根 URL，形如： 
    https://service-xxxx-xxxx.hk.apigw.tencentcs.com/
    或 Web 函数默认域名： 
    https://supabase-proxy-xxxx.hk.tencentscsapp.com
注意 URL 路径：要用根地址。如果 URL 末尾带 /release 之类前缀，不要带上——前端会拼成 .../release/auth/v1/... 转发就 404 了。用根路径即可。

5验证反代是否通

在浏览器访问上一步的根 URL：

https://你的函数URL/

应看到 Supabase 返回的 JSON（下列任一都算通）：

{"message":"No API key found in request"}    # 401/400 类
{"error":"requested path is invalid"}           # 404 类

不是 522 / 超时 / 一直转圈就说明反代通了。也可在函数控制台点「测试」看返回。

常见问题

Q1：测试时返回 502 proxy_error？

多半是运行环境不是 Node 18+（没有全局 fetch）。回到函数配置把运行环境改成 Node.js 18.15 重新部署。

Q2：URL 带路径前缀导致前端 404？

确保 SUPABASE_URL 用的是根地址。如果你拿到的 URL 是 https://xxx.apigw.../release/，把它发我时去掉 /release，或在函数的 API 网关里把路径设为 /。你不确定就把整段 URL 发我，我帮你判断。

Q3：同步时提示 body 太大 / 413？

云函数/API 网关对单次请求体有上限（通常 1~6 MB，看网关配置）。如果你的加密快照（含凭证图）很大可能超限。遇到的话告诉我，我帮你：① 把图片从快照里拆出去单独存；② 或换回轻量服务器方案（无此限制）。

Q4：首次访问慢 1~2 秒？

正常，云函数冷启动。登录后频繁同步不会冷启动。不影响使用。

Q5：免费额度够吗？会扣钱吗？

SCF 免费额度：每月 100 万次调用 + 40 万 GB·秒。个人财务同步一天几十次，远远用不完。不绑定套餐不会扣费。
